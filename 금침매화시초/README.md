# 금침매화시초 (金針梅花詩鈔 / 金针梅花诗钞)

> **청(淸)·주수동(周樹冬) 유고 · 주미성(周楣聲) 중정 · 도서출판 의성당(醫聖堂)**

[![Web Library](https://img.shields.io/badge/Web%20Library-Classics-blue?style=flat-square)](https://jaehyokim-sketch.github.io/classics/)

## 📖 작품 개요
청말(淸末) 명의 주수동(周樹冬, 1862년생)의 유고를 손자인 침구 대가 주미성(周楣聲, 1918~2007)이 발굴·중정(重訂)한 침구 명저. 역대 침구 문헌의 핵심 정수와 주씨 가문 4대의 임상 경험·심득을 수록하였으며, 특히 매화파(梅花派)의 독문 침방(針方), 자침 21절(진침부터 출침까지의 요령) 및 십사경 요혈시(要穴詩)를 유려한 시가(詩歌) 형식으로 집대성한 한국어 완역본.
