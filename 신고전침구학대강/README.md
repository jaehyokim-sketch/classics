# 신고전침구학대강 (新古典針灸學大綱)

> **황룡상(黃龍祥, 중국중의과학원 수석연구원) 저 · 인민위생출판사(人民衛生出版社), 2022년**

[![Web Library](https://img.shields.io/badge/Web%20Library-Classics-blue?style=flat-square)](https://jaehyokim-sketch.github.io/classics/)

## 📖 작품 개요
고전 침구 이론의 실증적 환원과 임상 표준화를 집대성한 황룡상 교수의 대표 결정판 한국어 완역본. 기병치막(器病治膜), 장침모자법(长针募刺法) 등 고전 임상 침구학의 정수를 현대 의학적 실증주의로 고증.
