# 영추 십이경맥 4대 병증 고증 & 동의보감 상병명 검색 탐색기

- **원전 및 판본 출전**:
  1. 곽애춘 편저, 《황제내경영추교주어역(黃帝內經靈樞校注語譯)》 제10편 경맥(經脈) · 제13편 경근(經筋)
  2. 황룡상 편저, 《중국침구학술사대강》 · 《중국침구경락통감》 (출토문헌 실증주의 8대 고증 체계)
  3. 허준 편저, 《동의보감(東醫寶鑑)》 (내경·외형·잡병 상병명 조목)
  4. 대한한의사협회, 《임상한의사를 위한 KCD지침서 개정증보판》 (KOICD KCD-9 및 한의 U코드)
- **주요 기능**:
  - 12경맥 시동병(是動病) · 소생병(所生病) · 십오락맥(十五絡) · 십이경근(十二經筋) 실시간 통합 검색
  - 4대 병증별 탭 분리, 음양속성(수삼음, 수삼양, 족삼음, 족삼양) 퀵 필터
  - 카드 뷰 / 비교 테이블 뷰 / 황룡상 학술고증 총람 뷰 지원
  - 원문·번역·고증 상세 모달 및 원클릭 클립보드 복사
