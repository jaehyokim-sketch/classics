# 중국고전침구학대강 (中國古典針灸學大綱)

> **황룡상(黃龍祥, 중국중의과학원 수석연구원) 저 · 인민위생출판사(人民衛生出版社), 2019년**

[![Web Library](https://img.shields.io/badge/Web%20Library-Classics-blue?style=flat-square)](https://jaehyokim-sketch.github.io/classics/)

## 📖 작품 개요
고전 침구 이론(경맥·수혈·침법·진단)의 발생 원리와 본원적 체계를 실증적으로 분석하고 30년 침구학술사 연구를 대강(大綱) 형식으로 집대성한 역작의 한국어 완역본.
