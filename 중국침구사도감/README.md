# 중국침구사도감 (中國針灸史圖鑑 / 中国针灸史图鉴) 상권·하권

> **황룡상(黃龍祥) 편저 · 청도출판사(靑島出版社), 2003년**

[![Web Library](https://img.shields.io/badge/Web%20Library-Classics-blue?style=flat-square)](https://jaehyokim-sketch.github.io/classics/)

## 📖 작품 개요
신석기 폄석부터 선진·진한 마왕퇴·장가산 출토 유물, 당·송·원·명·청대 침구동인 및 근대 전적 도판 1,932점을 상·하권으로 총망라하여 침구학술사 발전 궤적을 복원한 시각 침구사 최고 명저 한국어 완역본.
