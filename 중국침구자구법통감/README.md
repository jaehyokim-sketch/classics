# 중국침구자구법통감 (中國鍼灸刺灸法通鑑 / 中国针灸刺灸法通鉴)

> **황용상(黃龍祥) · 등양월(鄧良月) 주편 · 청도출판사(靑島出版社), 2023년**

[![Web Library](https://img.shields.io/badge/Web%20Library-Classics-blue?style=flat-square)](https://jaehyokim-sketch.github.io/classics/)

## 📖 작품 개요
선진(先秦) 시기부터 청대(淸代) 및 근현대에 이르기까지 2천 년 역대 침구 문헌의 호침·화침·도할 등 고대 자법, 이침·두피침·완과침 등 현대 미침 및 특수자법, 반흔구·격물구 등 구법(灸法) 전면과 고대 침구가부·소문유편 자법론을 총망라하여 집대성한 침구 자구 수기법의 최고 정본 통감 한국어 완역본.
