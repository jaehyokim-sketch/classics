# 중국침구학술사대강 (中國針灸學術史大綱 / 中国针灸学术史大纲)

> **황룡상(黃龍祥, 중국중의과학원 수석연구원) 저 · 화하출판사(華夏出版社), 2001년 초판 (84만 3천 자)**

[![Web Library](https://img.shields.io/badge/Web%20Library-Classics-blue?style=flat-square)](https://jaehyokim-sketch.github.io/classics/)

## 📖 작품 개요
선진(先秦)부터 청대·현대에 이르기까지 2천 년 침구학술 발전 전 과정을 引论·经络·腧穴·刺灸法·治疗 5개 부문으로 전면 재구성하여 침구학술사의 정체성을 학술사적 실증주의로 정립한 황룡상 교수의 불후의 기념비적 학술사 대작 원문 정본.
