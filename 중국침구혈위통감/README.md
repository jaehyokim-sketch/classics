# 중국침구혈위통감 (中國針灸穴位通鑑 / 中国针灸穴位通鉴)

> **왕덕심(王德深) 주편 · 청도출판사(靑島出版社), 2004년 제2판**

[![Web Library](https://img.shields.io/badge/Web%20Library-Classics-blue?style=flat-square)](https://jaehyokim-sketch.github.io/classics/)

## 📖 작품 개요
선진(先秦) 시기부터 청대(淸代) 및 근대에 이르기까지 역대 침구 문헌의 모든 수혈(腧穴) 명칭, 부위, 자침 깊이, 뜸장수, 취혈법, 혈위도판을 총망라하여 시대별로 집대성한 수혈 학술사의 최고 권위 정본 통감.
