# 중의백병명원고 (中醫百病名源考 / 中医百病名源考)

> **장강(張綱, 중국중의연구원 교수) 지음 · 인민위생출판사(人民衛生出版社), 1996년 초판**

[![Web Library](https://img.shields.io/badge/Web%20Library-Classics-blue?style=flat-square)](https://jaehyokim-sketch.github.io/classics/)

## 📖 작품 개요
고대 갑골문·금문·설문해자부터 한위진당(漢魏晉唐)·송명청(宋明淸) 전적을 집대성하여 중의학 100가지 주요 병명의 명칭 유래, 어원 변천, 병기 개념의 전개 과정을 실증 문헌학으로 해명한 한의 병명 어원학 최고의 명저 한국어 완역본.
