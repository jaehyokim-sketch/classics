# 침구수혈통고 (鍼灸腧穴通考 / 针灸腧穴通考)

> **황룡상(黃龍祥, 중국중의과학원 수석연구원) 저 · 인민위생출판사(人民衛生出版社), 2011년 판본 (144만 자)**

[![Web Library](https://img.shields.io/badge/Web%20Library-Classics-blue?style=flat-square)](https://jaehyokim-sketch.github.io/classics/)

## 📖 작품 개요
갑골문·금문·백서·한간·둔황권자 및 역대 수백 종 의학 전적을 망라하여 14경맥 경혈과 경외기혈 전체의 명칭 유래, 혈위 변천, 취혈법, 주치증 변천사를 실증적 문헌학으로 집대성한 20세기 수혈고증학의 최고 기념비적 역작 원문 정본.
