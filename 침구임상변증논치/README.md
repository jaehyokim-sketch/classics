# 침구임상변증논치 (鍼灸臨床辨證論治 / 针灸临床辨证论治)

> **이세진(李世珍)·이전기(李傳岐)·이완량(李宛亮) 지음 · 인민위생출판사(人民衛生出版社), 2017년 제2판**

[![Web Library](https://img.shields.io/badge/Web%20Library-Classics-blue?style=flat-square)](https://jaehyokim-sketch.github.io/classics/)

## 📖 작품 개요
40여 년의 임상 경험을 토대로 명대 진회(陳會)의 『신응경(神應經)』 염전보사법(捻轉補瀉法)과 장부·경락·팔강변증에 입각한 침구 선혈(選穴)·배혈(配穴) 및 자침 보사의 원칙과 수기법을 구체적인 임상 질환별로 완벽히 체계화한 명저 한국어 완역본.
