# 황용상간침구 (黃龍祥看鍼灸 / 黄龙祥看针灸)

> **황룡상(黃龍祥, 중국중의과학원 수석연구원) 저 · 인민위생출판사(人民衛生出版社), 2008년 (도설중의 총서)**

[![Web Library](https://img.shields.io/badge/Web%20Library-Classics-blue?style=flat-square)](https://jaehyokim-sketch.github.io/classics/)

## 📖 작품 개요
수혈의 탄생, 경락의 발견, 명당공혈의 변천, 침구동인의 역사와 침구 진료의 삼위일체 원리를 154점의 정밀 도판과 함께 '인체 교향악의 음향사'라는 독창적 통찰로 풀어낸 황룡상 교수의 그림 침구학 입문·통찰 명저 한국어 완역본.
